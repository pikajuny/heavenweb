# 라운지 정리 및 관리자 설정

라운지는 덱파워 랭킹, 헤븐 골든글러브, 구단 상세/비교만 제공합니다. 게시판·댓글·읽음 기록·공지·알림장·HEAVEN LINK 기능과 Supabase 런타임 의존성을 제거했습니다. 외부 DB의 기존 데이터는 삭제하지 않습니다.

## 배포 전 설정

중심 스프레드시트의 유저DB에서 I열 헤더를 `관리자`로 설정하고, 관리자 Google 계정에 해당하는 행을 `TRUE`로 표시합니다. 체크박스도 사용할 수 있습니다. 일반 사용자는 `FALSE` 또는 빈칸으로 둡니다. 코드는 열 위치 대신 `관리자` 헤더명으로 열을 찾습니다. 시트·헤더·해당 이메일이 없으면 권한을 부여하지 않습니다. 기존 `ADMIN_EMAILS` 스크립트 속성은 더 이상 사용하지 않습니다.

일반 자동 로그인 캐시는 관리 권한으로 인정하지 않습니다. 상단 `관리` 버튼에서 `Google 재인증`을 누르면 로그인으로 확인된 이메일을 유저DB A열 이메일과 대조한 뒤 `관리자` 값이 `TRUE`인지 GAS에서 매 요청 확인합니다. 세션은 탭의 sessionStorage와 GAS 캐시에 보관되며 최대 6시간 유효합니다. GAS 캐시가 일찍 만료되면 재인증합니다. 관리자 등록 해제는 다음 요청부터 적용됩니다.

관리 화면은 초대코드 조회·회원 목록·강제탈퇴를 제공합니다. 본인 탈퇴도 Google 인증 계정이 해당 구단 소유자인지 확인하며, 자동 로그인 사용자나 세션 만료 사용자는 탈퇴 창에서 `Google 재인증` 후 다시 확인합니다.

## 배포

1. `gas/`에서 `push.gas` — 관리자 API 및 인증 검사 배포.
2. `web/`에서 `push.git` — 라운지 UI와 API 제거 반영.
3. 새 화면에서 랭킹/골든글러브와 관리자 재인증을 확인합니다.

관리 API 변경 때문에 두 배포를 연이어 진행하세요. 구버전 화면의 회원 관리·탈퇴 기능은 새 GAS 배포 후 새 화면 배포 전까지 사용할 수 없습니다. 기존 Supabase 권한 기반 API가 남는 시간을 줄이려면 두 배포를 같은 작업 시간에 진행하세요.

새 배포 확인 후 Vercel의 `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `SUPABASE_SERVICE_ROLE_KEY`가 다른 용도로 사용되지 않는지 확인하고 제거할 수 있습니다. `GAS_API_URL`/`GAS_WEB_APP_URL`은 유지합니다. 외부 Supabase 프로젝트·테이블 삭제는 별도 작업입니다.

## 검증

`web/`에서 `npm test`. 관리자 승인·거부·만료·빈 명단·본인 탈퇴 소유권과 랭킹 직접 진입을 테스트합니다. 실제 Google OAuth와 Sheets 변경은 배포 후 운영 계정으로 확인해야 합니다.
