# [공지] 시트로 업데이트 소식 작성하기

중심 스프레드시트에 `[공지]` 시트를 만들고 첫 행에 다음 헤더를 입력합니다. 헤더명으로 열을 찾으므로 순서는 바꿀 수 있습니다.

| 작성일 | 제목 | 내용 | 공개 | 작성자 |
| --- | --- | --- | --- | --- |
| 2026-11-04 | 스킬점수표 업데이트 | 변경 내용과 안내를 작성합니다. | TRUE | 관리구단 |

한 행이 공지 한 건입니다. `공개`는 체크박스 또는 TRUE/FALSE를 사용합니다. TRUE인 행만 웹으로 전달하며, FALSE/빈칸은 숨깁니다. 제목이 빈 행도 표시하지 않습니다. 작성일은 시트 날짜 값 또는 `2026-11-04`, `2026-11-04 14:30` 형식으로 입력합니다. 날짜가 최신인 글부터 표시하고 같은 날짜이면 아래쪽 행을 먼저 표시합니다. 내용 셀의 줄바꿈을 보존하며 HTML/Markdown 문법은 해석하지 않습니다.

라운지 위쪽에 왼쪽 목록·오른쪽 본문으로 표시합니다. 최신 글이 자동 선택되며 목록은 페이지당 10건입니다. 모바일에서는 목록 위·본문 아래로 표시합니다. 공지 새로고침 또는 라운지 재진입으로 시트 수정 사항을 다시 불러옵니다. 이 읽기 API는 시트를 생성·수정하지 않습니다.

## 배포

1. `gas/`에서 `push.gas`로 코드 업로드.
2. Apps Script → 배포 → 배포 관리 → 기존 웹앱 수정 → 새 버전 → 배포. 현재 `push.gas`는 코드 업로드만 수행하므로 이 단계가 필요합니다. 기존 배포를 수정해 URL을 유지합니다.
3. `web/`에서 `push.git`로 프론트엔드 반영.
4. `[공지]`에 테스트 글을 작성하고 라운지의 공지 새로고침으로 확인합니다.

Supabase는 사용하지 않습니다. 시트에서 직접 편집하거나 웹의 공지 관리에서 작성·수정할 수 있습니다. 댓글 기능은 없습니다.


## 웹에서 작성·수정

상단 관리에서 관리자 Google 계정으로 재인증한 뒤, 공지 영역의 공지 관리를 누릅니다. 유저DB의 관리자 열이 TRUE인 계정만 사용할 수 있습니다. 글쓰기 또는 글 선택 후 수정을 누르면 제목·내용·공개 여부를 편집합니다. 새 글은 기본 비공개이며 공개하기를 체크해야 일반 사용자에게 보입니다. 관리 모드에서는 비공개 글도 표시됩니다. 공개 글 보기를 누르면 일반 목록으로 돌아갑니다.

작성일은 새 글 저장 시 서버가 기록하고 수정할 때 유지합니다. 저장 도중 다른 관리자가 수정했거나 시트 행이 이동하면 덮어쓰지 않고 새로고침을 요청합니다. 실패한 저장은 작성창 입력을 유지합니다. 인증이 만료됐다면 작성창의 Google 재인증 후 다시 저장할 수 있습니다. 시트 쓰기 중 오류가 발생한 경우 일부 내용이 반영될 수 있으므로 해당 공지는 비공개로 두고 목록을 새로고침해 확인합니다.


작성자 열은 E1에 `작성자`로 추가합니다. 웹에서 새 글을 작성하면 인증된 관리자 이메일과 유저DB를 대조해 구단명을 서버에서 저장합니다. 작성자 입력은 받지 않습니다. 다른 관리자가 수정해도 원작성자는 유지합니다. 기존 글의 작성자가 비어 있으면 표시하지 않으며 시트에서 직접 입력할 수 있습니다. 기존 글은 작성자 열이 없어도 조회할 수 있으나 웹 저장에는 해당 헤더가 필요합니다.
